# Schindler's List - app interattiva

App HTML/CSS/JavaScript da caricare su GitHub Pages.

## Come usarla
1. Crea un nuovo repository su GitHub.
2. Carica tutti questi file mantenendo la cartella `assets`.
3. Vai su Settings > Pages.
4. In "Branch" scegli `main` e cartella `/root`.
5. Apri il link generato da GitHub Pages.

## Struttura
- `index.html`: struttura dell'app
- `style.css`: grafica e pulsanti
- `script.js`: cambio schermata
- `assets/`: immagini delle slide
